# SpaceWalk

macOS SwiftUI 原型：把手机视频抽帧，使用 COLMAP 恢复相机轨迹与稀疏彩色 3D 点云，可生成粗略三角网格预览，再在 SceneKit 中自由浏览。全程本地处理。**当前输出仅供预览，不能直接作为游戏场景。**最终目标与验收要求见 `docs/dev/GAME_SCENE_TARGET.md`。

## 运行

需要 macOS 14+、Xcode 及命令行工具，并安装 `ffmpeg` 与 `colmap`：

```bash
brew install ffmpeg colmap
swift run SpaceWalk
```

也可以打开构建产物 `dist/SpaceWalk.app`。这个本地构建的应用未经 Apple 公证；后续正式分发需要开发者签名与公证。

导入手机视频后点击「开始重建」。项目与生成的 PLY 保存在 `~/Documents/SpaceWalk/<UUID>/`。也可以直接打开已有的 PLY 点云。

每次重建都会在任务目录的 `logs/` 下保存抽帧、特征提取、画面匹配、空间重建和导出日志。失败时界面会指出失败阶段与日志路径；侧边栏的「打开任务文件夹与日志」可直接查看。应用会在 COLMAP 产生多个子模型时选择点数最多的一个。

重建后可在侧边栏切换点云与粗略表面预览，并选择 PLY、OBJ、GLB、XYZ、PCD 导出。显示粗略表面时，PLY、OBJ、GLB 包含三角面；XYZ、PCD 始终为点云。粗略网格由稀疏点估算，不包含照片纹理，可能有缺口或错误表面。部分软件可能忽略 OBJ 的顶点颜色扩展。

## 拍摄与限制

建议拍摄至少 20 秒，缓慢向前或侧向移动，覆盖卧室不同角度，保持画面重叠和清晰。纯原地旋转、严重运动模糊、重复纹理或大面积无纹理墙面会导致重建失败。短视频采用全量画面匹配。当前表面预览由稀疏点推算，**不是完整、带照片纹理的卧室模型**。此 Mac 的 COLMAP 构建不支持 CUDA，而它的稠密立体重建要求 CUDA。要获得更完整的室内场景，需要进一步采用可在 Mac 运行的稠密重建方案，或采集带深度数据的素材。
