# 卧室游戏场景目标

用户目标（2026-10-13）：从自己的卧室采集素材，得到可导入其他应用、在游戏中自由行走的房屋场景。

## 可交付结果

- 连续的地面、墙、天花板和主要家具；房间尺寸与方向正确。
- 有可见的照片纹理与 UV，避免仅有点云或无材质三角面。
- 分离或标记可碰撞区域，导入目标应用后可以设置行走与碰撞。
- 提供目标应用支持的场景文件，并在目标应用中实测导入、材质、尺度与碰撞。
- 对未拍到的背面、遮挡区域明确标记为待补扫或人工修补，不声称自动恢复真实细节。

## 当前原型与差距

- 现有 FFmpeg + COLMAP 路径仅建立稀疏相机/点云与粗略 Delaunay 表面；导出的 GLB/OBJ 不能视为可直接使用的游戏场景。
- 本机 COLMAP 的稠密立体重建要求 CUDA，无法在此 Mac 上运行。
- Apple RoomPlan 适用于带 LiDAR 的 iPhone/iPad，能提供房间结构、尺寸和物体类别，可导出 USD/USDZ；它不是从普通视频离线恢复照片纹理的替代品。
- Apple Object Capture 主要面向围绕物体拍摄的多视角照片，不应当作为完整卧室重建的默认方案。

## 接下来的验证顺序

1. 获取原视频并检查时长、清晰度、运动轨迹、视角覆盖和遮挡。确认目标应用/引擎及手机是否有 LiDAR。
2. 若有 LiDAR，优先采集 RoomPlan/深度数据建立房间结构，再补拍照片获取材质与家具细节。
3. 若只有普通视频，评估可用的 GPU 稠密重建或场景重建方案；完整网格、纹理烘焙和清理都需要单独验证。
4. 在目标应用中完成导入验收。只有通过后，界面才应标记为「游戏场景就绪」。
